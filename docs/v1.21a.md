# v1.21a — Character Art Overhaul / Team 7

Date: 2026-11-24. Base: approved v1.20e (c9d9e8addb195080cfe54b4756f43148a234fd04). Experimental branch `feature/v121-character-art`. The unapproved title polish v1.20e.1 is not included.

## Scope
- Original 48×64 pixel-art sprites for Naruto, his clones, Sasuke, Sakura and Kakashi. `team7-art.js` provides the visual palette and rasterization; `pixel-art.js` preserves animation indices, logical coordinates, direction, gear overlays and red-eye variant. Legacy 24×32 generator remains available as fallback. The renderer derives crop dimensions from the selected atlas, not fixed dimensions. Other actors, special Sasuke forms, bosses and effect textures retain their prior art.
- No changes to collision, stats, save data, combat timing, world or menu other than version label. Existing illustrated Naruto HUD remains unchanged. Portrait crops in the renderer use the updated atlas. Bingo Book imagery remains unchanged.
- Atlas dimensions 3072×256 for enhanced characters; each contains 64 columns and 4 rows. Compared with original atlases, each enhanced base texture adds 2.25 MiB of uncompressed RGBA pixel data; five base atlases add 11.25 MiB before gear variants and driver overhead. No additional artwork downloads. No claim of measured game FPS.
- `character-art-lab.html` renders before/after, directions, animation families, gear and Kyūbi eyes using the same generator as the game. It is not a gameplay simulation.

## Verification
Chromium isolated lab with actual JS modules inlined as data URLs (local HTTP blocked). Inspected all 2,048 frames across eight actor kinds, including 1,280 enhanced frames. No empty frames or partial alpha pixels; gear and Kyūbi variant pixel hashes differ; Zabuza legacy art is pixel-identical to its original generator. Five viewport sizes, no horizontal overflow; no page JS errors. Syntax checks pass. Full WebGL gameplay, memory/FPS and Cloudflare deployment not verified. Portraits are pixel crops, not new anime illustrations.
