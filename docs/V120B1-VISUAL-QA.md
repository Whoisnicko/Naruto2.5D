## Reproduce locally
Install Python Playwright (`pip install playwright`) and Chromium. From repository root run `python tests/visual-qa.py visual-qa-output`. If Chromium is installed elsewhere set `CHROMIUM_PATH` to its executable. Script embeds repository markup/styles/assets and uses fixture JS, then writes captures and JSON results. It returns failure for detected bounds/overlap/overflow or missing asset groups. Serve repo via a local HTTP server and open `ui-lab.html` for manual controls. Normal index loads unchanged gameplay except version text. Test actual deployment separately.
