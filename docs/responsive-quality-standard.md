# Mandatory responsive quality standard

User requirement, 26 November 2026: every interface of the game must adapt to varying browser resolutions. Apply to all future phases and include existing surfaces in the regression backlog. No phase is visually complete without a responsive review. Test real browser at 2560×1440, 1920×1080, 1366×768, 1024×768, 844×390 landscape, 390×844 portrait; also resize live and browser zoom 125%/150%. Check HUD, dialogs, menus, inventory, equipment, selector, notifications, map, loading, combat, boss arena and cinematics. No clipped or overlapping controls, no hidden critical action, no horizontal page overflow, appropriate internal vertical scrolling, scalable canvas/camera without distortion, readable labels, keyboard focus, touch targets ideally 44 CSS px. Do not assume responsive layout equals touch gameplay support. Preserve actual approved assets and require review before integrating any new visual UX. Mark each resolution explicitly validated or pending; never infer browser quality from syntax/DOM simulation. Existing surfaces not yet fully audited; no blanket claim of responsive compliance.
