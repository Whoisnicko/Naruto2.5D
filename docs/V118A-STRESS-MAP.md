## Playtest protocol
- Use same preset, browser/window size, resolution and character for both runs. Sandbox > Stress Test > 24 enemies, attack normally for 15s, reopen Sandbox to record report. Repeat 48. Keep focus; no pause or scene transitions.
- Verify movement, attacks, clone targeting, guard/charge, cooldowns, rain, region and interior transitions, map refresh, and return from Sandbox.
- Compare actual FPS/p95/max/min resolution and peaks. Target 60 FPS floor where feasible; prior ~99 FPS was a separate player observation, not directly comparable to this heavier scenario.
- No claim of frame-rate improvement until browser measurement. GPU/audio and visual layout validation remain pending. Visual Naruto theme and large world redesign remain separate.
