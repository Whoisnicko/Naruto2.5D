# v1.20d.1 — Konoha Legacy (experimental)

Base: v1.20d (a668b0c96caa4a3a1fe116790ac47f3ae6d81a43). Main stays at approved v1.20c.1. Actual approved HUD sheet reused for five WebP assets: paper, header, banner, kunai and Konoha plate. Existing atlas for Rasengan, dash and clones, with original vector icons as fallback and for other techniques. No official anime screenshots or typeface. Inventory/equip mechanics remain unchanged. Three branches with actual prerequisite links, ten Naruto nodes, six per other character. Retain IDs bond and endurance; bond now grants one clone rather than damage. CloneII (+1 at level 4), cloneIII (+1 at level 6), max 5. Recast fills missing slots; existing clones retained, each one hit, duration unchanged except endurance (5 to 7 seconds). Additional optional guardMaster (+2 defense) and chakraMaster (+1 chakra/s) balancing proposals, one point each. Giant unchanged, requires focus and scroll. Older saves with existing IDs validated; new skills not backwards compatible with previous version validators. No save schema change. No changes to bosses or other characters' skill stats.

QA: 33 Chromium fixture assertions in seven viewport sizes, using actual UI/data source inlined into test HTML and actual textures embedded. Node syntax checks and extracted real spawn block checks. Full game/rendering/performance and Cloudflare deployment unverified.
